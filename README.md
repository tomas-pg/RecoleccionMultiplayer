# Recolección Multiplayer

Juego 3D multijugador

Tomás Pérez Gómez

Cómo jugar
1. Un jugador elige "SER HOST". Le pasa su IP local al otro.
2. El otro elige "UNIRSE (CLIENTE)", escribe la IP y conecta.
3. El host toca "COMENZAR PARTIDA".
4. Recolectá objetos antes de que termine el tiempo:
   - Cubo amarillo: +1
   - Esfera violeta: +3
   - Cápsula roja: -2 (evitala)
5. Gana quien tenga más puntos.

Controles
- WASD / flechas: moverse
- Espacio: saltar

Requisitos
- Unity (versión 6000.3.11f1)
- Puerto UDP 7777 abierto para jugar en red local
